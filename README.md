# AlSayegh Jewelry Store Demo

متجر React عربي تجريبي لمصنع الصايغ للمجوهرات، مبني كواجهة عرض تفاعلية كاملة من اليمين إلى اليسار. يحتوي على الصفحة الرئيسية، المنتجات، التصنيفات، المجموعات، الأطقم، أداة تكوين طقم مخصص، السلة، المفضلة، الدفع التجريبي، صفحة عن المصنع الموحّدة، الفروع، والتواصل.

## التقنيات

- React + TypeScript + Vite
- React Router
- Zustand مع LocalStorage
- React Hook Form + Zod
- Framer Motion
- Lucide React
- React Helmet Async
- Tailwind CSS مثبت وجاهز للتوسع، مع اعتماد التصميم الحالي على CSS tokens مخصصة

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## بنية مهمة

- `src/data.ts`: المنتجات، التصنيفات، المجموعات، الأطقم، الفروع، الفريق، الأسئلة الشائعة، وخطوات التصنيع.
- `src/store.ts`: السلة، المفضلة، الطقم المخصص، آخر المنتجات المشاهدة، وسجل البحث.
- `src/App.tsx`: الصفحات، المسارات، المكونات الرئيسية، النماذج، وSEO.
- `src/index.css`: ألوان الهوية، RTL، الاستجابة، وتفاصيل الواجهة.

## تعديل البيانات

عدّل المنتجات والفروع والموظفين مباشرة من `src/data.ts`. جميع الأسعار والأوزان والصور وبيانات الفروع والموظفين Demo Data ويمكن استبدالها لاحقاً ببيانات العميل الحقيقية أو API.

## تعديل الهوية

الألوان الأساسية معرفة في `src/index.css` داخل `:root`، ومنها الأخضر الداكن والذهبي والعاجي. يمكن استبدال الصور من روابط `asset` وحقول `images` داخل `src/data.ts`.

## ربط Backend لاحقاً

استبدل مصفوفات `src/data.ts` بطبقة API، ثم اربط `src/store.ts` بنقاط حفظ السلة والمفضلة وحساب المستخدم. تجربة الدفع الحالية شكلية ولا ترسل بيانات لخادم.
